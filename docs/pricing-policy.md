# Hubicx pricing policy

Актуально на 2026-07-01.

## Базовая формула v2

- Минимальная розничная цена теперь считается через unit economics:
  `provider_cost_rub / (1 - tax_rate - acquiring_total_rate - target_net_margin_rate)`.
- Стартовые параметры:
  - `tax_rate = 0.06` для УСН 6% доходы;
  - `acquiring_rate = 0.025`;
  - `acquiring_vat_rate = 0.22`, применяется к комиссии эквайринга;
  - `target_net_margin_rate = 0.30`;
  - `partner_share_from_profit_rate = 0.25`, только от чистой прибыли и только для активного партнёра;
  - `token_floor_rub = 0.55`, минимальная цена токена по Studio;
  - округление рекомендованной цены — вверх до 10 токенов.
- Старый ориентир `ceil(provider_cost_usd * 300)` можно использовать как стресс-проверку, но не как основную формулу.
- Для цены за секунду сначала умножается стоимость секунды на длительность.
- Результат округляется вверх до удобного значения, обычно до 10 токенов.
- Для разрешений используется реальное соотношение стоимости провайдера, а не визуальный коэффициент качества.

Калькулятор реализован в `backend/app/services/unit_economics.py`, admin preview — `POST /admin/pricing/economics-preview`.

Пример Seedance 2.0 normal 720p 15 сек при `$0.3034/sec` и курсе `78.2652`: себестоимость Fal ≈ `356.18 ₽`, рекомендованная розница ≈ `584.39 ₽`, то есть `1070` токенов при минимальном Studio-токене.

## Стоимость токена

| Пакет | Рублей за токен |
| --- | ---: |
| 300 токенов | 0.830 |
| 1 000 токенов | 0.790 |
| 3 000 токенов | 0.663 |
| 10 000 токенов | 0.599 |
| Шаблоны Mini | 0.988 |
| Шаблоны Plus | 0.740 |
| Creator | 0.828 |
| Creator Pro | 0.614 |
| Studio | 0.550 |

Все модели должны оставаться прибыльными при цене Studio, а не только при разовых пополнениях.

## Текущие решения

- Seedance 2.0 рассчитывается по разрешению и фактической длительности от 4 до 15 секунд.
- Seedance Standard: базовая цена 720p/5 секунд — 460 токенов.
- Seedance Fast: базовая цена 720p/5 секунд — 370 токенов.
- Seedance Mini: базовая цена 720p/5 секунд — 240 токенов.
- Nano Banana 2 Lite: 25 токенов за 1K-изображение, множитель только по количеству изображений.
- Nano Banana Pro: 1K и 2K стоят одинаково, 4K стоит в два раза дороже согласно тарифу Fal.
- Цена шаблона формируется из модели и её параметров. Отдельная скрытая наценка шаблона не применяется.

## Контроль изменений

1. Перед включением новой модели зафиксировать endpoint, единицу биллинга и источник цены.
2. Проверить худшую комбинацию качества, длительности, аудио и количества результатов.
3. Рассчитать цену по коэффициенту 300 токенов за доллар.
4. Добавить серверное правило и проверку `price-preview`.
5. Повторять аудит раз в месяц и после изменения цены провайдера или курса более чем на 10%.

Источники цен: официальные страницы моделей Fal.ai и API `GET /v1/models/pricing`. Курс для контрольного расчёта: официальный USD/RUB Банка России.
